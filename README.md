# Training Workspace

This workspace contains a blended planning and development project focused on both a long-term, multiyear training framework and a minimal viable product (MVP) implementation.

## Structure

- `2026/`: The structured training plan for the current year, including macro, meso, and micro planning documents. Future years such as `2027/` will be added as new yearly planning and results folders.
  - `Bloques/`: Training blocks divided into phases such as reconstruction, aerobic development, functional consolidation, advanced construction, intelligent reset, and maintenance.
  - Weekly and daily templates, plus individual week folders for detailed routine planning.
- `MVP/`: Minimum viable product documentation and a backend application prototype.
  - `API-Minima.md`, `MVP-Arquitectura.md`, and other architecture and status docs.
  - `backend/`: Python backend app with FastAPI-style structure, database configuration, and tests.
- `Principios/`: Core guiding principles and philosophy for the training project.

## Purpose

This workspace is designed to:

- document and organize a full-year training strategy for 2026,
- support structured periodization across multiple training blocks,
- maintain a lightweight MVP backend for tracking progress, analytics, and planning data,
- preserve the principles and rationale behind the training methodology.

## Use

Open the workspace and review:

- `Principios/Principios.md` for the guiding philosophy,
- `2026/Plan-2026.md` for the yearly strategy,
- block folders under `2026/Bloques/` for weekly training templates,
- `MVP/` for the application architecture and backend implementation.
