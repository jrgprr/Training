# Bloques 2026

Esta carpeta organiza la microplanificación del año por bloques meso y semanas.

Estructura:
- `B1-Reconstruccion-solida`: 6 semanas base.
- `B2-Construccion-aerobica-extensiva`: 7 semanas base.
- `B3-Consolidacion-funcional`: 5 semanas base.
- `B4-Construccion-avanzada-y-disfrute`: 8 semanas base.
- `B5-Reset-inteligente`: 4 semanas base.
- `B6-Mantenimiento-ligero-y-transicion`: 4 semanas base.

Criterio de uso:
- Cada bloque contiene una carpeta `Semanas`.
- Cada semana es una unidad de microplanificación.
- Si un bloque real acaba teniendo una semana menos o más, se puede renombrar o ampliar sin tocar la lógica general del año.
