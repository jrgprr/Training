# B3 - Consolidacion y absorcion

## 1. Identificacion

- Periodo orientativo: segunda mitad de julio.
- Nivel: meso ciclo.
- Funcion dentro del macro: absorber la carga acumulada en B2 y confirmar que la base es util.
- Duracion orientativa: 3-4 semanas.

## 2. Objetivo del bloque

- Objetivo principal: estabilizar lo construido y bajar la presion de progreso.
- Objetivo secundario: confirmar que la semana sigue siendo repetible con buena sensacion.
- Objetivo complementario: mantener peso y fuerza en una zona compatible con entrenar bien.

## 3. Criterios de entrada

- Acumulacion aerobica relevante en B2.
- Primeras senales de necesidad de estabilizacion o conveniencia de bajar presion.
- Base suficiente para mantener frecuencia sin exigir crecimiento continuo.

## 4. Criterios de salida

El bloque se considera completado si la mayor parte de lo siguiente ya es normal:
- sensacion de frescura recuperada,
- carga previa absorbida sin retroceso funcional,
- semana repetible con control,
- y disposicion para un segundo bloque de construccion.

## 5. Riesgos principales

- Confundir consolidar con dejar de estimular.
- Mantener demasiada dureza y no absorber realmente el bloque anterior.
- Bajar tanto la carga que se pierda continuidad.

## 6. Patron micro esperado

La unidad micro de este bloque es la semana.

Cada semana debe dejar claro:
- como se reduce la presion sin perder estructura,
- que indicadores confirman absorcion,
- como se mantiene la base sin buscar crecimiento fuerte,
- y en que momento se puede abrir el paso a B4.

## 7. Estructura del bloque

- Primera semana: alivio relativo y lectura de sensaciones.
- Semanas siguientes: consolidacion de rutina y control aerobico.
- Cierre: decision de pasar a nueva construccion o prolongar estabilizacion.
