# Plantilla de registro diario semanal

Uso:
- Duplicar esta plantilla dentro de la carpeta de la semana como `Registro-Diario.md`.
- Completar cada dia en cuatro momentos: manana, tras la sesion, tarde-noche y cierre.
- Priorizar datos automaticos de Garmin y anadir a mano solo lo que no registran los dispositivos.
- Si un campo no aplica, dejarlo vacio o marcar `n/a`.

Datos base de dispositivos:
- Garmin S2 para peso corporal.
- Garmin Fenix 5X Plus para actividad diaria, pulso, paseos y seguimiento general.
- Garmin Edge 530 para sesiones de bici.
- Garmin Vector 3 para potencia y cadencia en bicicleta.
- Garmin pod running dynamics si aparece trote o carrera.
- Bicicleta de spinning con velocidad, cadencia, distancia y potencia para sesiones indoor.
- Cinta de correr para caminar o correr indoor.

Regla de registro:
- cuando una sesion prevista en exterior se haga indoor por meteorologia, dejarlo indicado en `Plan previsto`, `Realizado` y `Dispositivo usado`.
